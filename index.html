Make something unexpected

Generator mode: switch from Edit tables to Generator using the top buttons. Choose Single table to pick one weighted entry from a selected table.

Multiple tables: select several tables to roll together. For example: a settlement, a local problem, and a hidden truth.

Sub-tables: choose a table beneath an entry. When that entry is rolled, its text is followed by a roll on that table. Sub-tables can have their own sub-tables. Circular links stop with a visible warning.

Inline tables: use the Reference button on an entry, or type [Table name]. For example: A [Creature] guards [Treasure]. Table names must match exactly. Inserted references keep working after table renames. Repeated references roll independently.

Meta-combined: add named combinations of tables and assign weights. A 6:3:1 split gives 60%, 30%, and 10% odds. Each result chooses a combination; Reroll unlocked keeps that combination. Save the setup as a named generator.

Repeat rules: no-repeat batches draw each entry at most once, including nested references. Deck mode keeps entries depleted until reset or reload. Weights affect selection until entries are depleted.

Organization: give tables a folder and comma-separated tags. Search matches names, folders, and tags.

Notebook: save generated results, edit their text and notes, and export text. JSON backups include the notebook.

Dice ranges: Edit dice ranges converts a complete, gap-free set of ranges to weights.

Saved generators: save a name, mode, table choices, per-table counts and batch size. JSON backups include saved generators.

Lock and reroll: lock a result part to keep it, then reroll the unlocked parts of that result. Individual Reroll buttons change only that part. Results and locks last for this session.

Dice in text: write [[2d6+3]] or [[1d20]] inside an entry to roll dice as part of the result.

Import: JSON restores linked collections. CSV uses text,weight,subtable columns; subtable names must uniquely match an existing table. Plain text creates one entry per line.

Storage: changes save automatically on this device and browser. They are not synced to GitHub. Export JSON for backups or to transfer between devices.

The included tables are editable examples. Create, duplicate, or delete any table to make the collection your own.

Edit combination

Select every table included in this outcome. Counts control how many times each selected table rolls.

Edit dice ranges

Enter inclusive ranges such as 1–35, 36–80, 81–100. Ranges must cover the die exactly, in row order. Applying ranges updates entry weights.

Result notebook

Saved on this device and included in JSON backups. Edits save automatically.

Entry conditions

Match entry text selected in an earlier roll of this result, before dice or references expand. Missing earlier rolls never match. Tables roll in the listed order. A parent entry is available to its sub-tables.

No conditions means always eligible. Odds are recalculated among eligible entries; editor dice ranges show the full table. Use JSON backup to preserve conditions.

Insert a table result

Inserts [Table name] at the entry’s cursor. Use several references to build a sentence. Each reference rolls independently.
